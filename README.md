# CAA - Cryptographie Avancée

Ce dépôt contient les projets réalisés dans le cadre du cours *Cryptographie Avancée*. Les laboratoires couvriront différents concepts et implémentations liés à la cryptographie moderne, avec une attention particulière à la sécurité des systèmes cryptographiques et à l'utilisation d'outils pour leur gestion.

Chaque projet sera documenté avec une description détaillée de la méthode, des outils utilisés, ainsi que des solutions implémentées.
